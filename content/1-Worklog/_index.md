In this section, I will present my weekly worklog during the internship program. The worklog summarizes the learning process, practical activities, and project development tasks completed each week.

I completed the internship program over **12 weeks**. During this period, I learned fundamental AWS services, practiced deploying cloud resources, and applied AWS technologies to develop the **Dental Clinic Management System** project.

**Week 1:** [Introduction to AWS and the internship program](1.1-week1/)

**Week 2:** [Learning AWS Management Console, AWS CLI, and configuring the AWS environment](1.2-week2/)

**Week 3:** [Learning Amazon EC2, Amazon EBS, Elastic IP, and creating virtual machines](1.3-week3/)

**Week 4:** [Learning AWS IAM, Amazon VPC, Amazon S3, and practicing identity, networking, and storage management](1.4-week4/)

**Week 5:** [Learning Amazon RDS, Amazon DynamoDB, Amazon CloudWatch, and database management](1.5-week5/)

**Week 6:** [Learning application deployment on Amazon EC2 and practicing Docker fundamentals](1.6-week6/)

**Week 7:** [Learning Elastic Load Balancing, Auto Scaling Groups, and Amazon CloudWatch Alarms](1.7-week7/)

**Week 8:** [Starting the Dental Clinic Management System project and designing the AWS architecture](1.8-week8/)

**Week 9:** [Developing the Amazon DynamoDB data model, User and Doctor APIs, and JWT authentication](1.9-week9/)

**Week 10:** [Developing the Admin Dashboard, Service, Doctor, and Appointment Management modules, and completing the AWS.drawio architecture diagram](1.10-week10/)

**Week 11:** [Deploying the application to Amazon EC2, integrating Amazon SNS, and monitoring the system with Amazon CloudWatch](1.11-week11/)

**Week 12:** [Completing the project, performing system testing, optimizing performance, and finalizing the project documentation](1.12-week12/)
