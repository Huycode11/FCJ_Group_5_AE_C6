* Learn about Elastic Load Balancing (ELB).

### Week 7 Achievements:

* Understood the role of Elastic Load Balancer in distributing incoming traffic.

* Learned the differences between:
  * Application Load Balancer (ALB).
  * Network Load Balancer (NLB).
  * Target Groups.

* Understood how Auto Scaling Groups automatically adjust the number of EC2 instances.

* Successfully configured Auto Scaling policies for dynamic scaling.

* Learned how to use Amazon CloudWatch Alarms to monitor AWS resources.

* Monitored important metrics such as CPU Utilization and Network Traffic.

* Understood how ELB, Auto Scaling Groups, and CloudWatch work together to build highly available and scalable AWS architectures.

* Improved practical skills in designing AWS solutions based on High Availability and Scalability best practices.
