### Week 2 Objectives:

* Get acquainted with members of First Cloud AI Journey and understand the internship regulations.
* Learn the overview of AWS Cloud and basic AWS service groups.
* Know how to use AWS Management Console to access and manage services.
* Install, configure and use AWS CLI for basic operations.
* Practice creating and connecting to an EC2 server on AWS.

### Week 2 Achievements:

* Understood the basic concept of cloud computing and the role of AWS in providing cloud infrastructure, platforms and services.

* Learned the basic AWS service groups, including:

  * Compute
  * Storage
  * Networking
  * Database
  * Security
  * Monitoring

* Successfully created an AWS Free Tier account for learning and practicing AWS services.

* Became familiar with AWS Management Console and learned how to:

  * Search for services on AWS
  * Access the management interface of each service
  * View resource information
  * Create and manage some basic resources

* Installed and configured AWS CLI on the personal computer, including:

  * Access Key
  * Secret Key
  * Default Region
  * Output Format

* Learned how to use AWS CLI to perform some basic operations such as:

  * Check AWS account configuration information
  * View the list of regions
  * Query EC2 service information
  * Create and manage Key Pairs
  * Check information of active resources

* Understood the basic components of Amazon EC2, including:

  * EC2 Instance
  * AMI
  * Instance Type
  * Security Group
  * Key Pair
  * EBS Volume

* Successfully practiced creating an EC2 Instance and connecting to the server using SSH.

* Learned how to attach an EBS Volume to an EC2 Instance and check the storage capacity on the server.

* Understood the difference between managing AWS resources through the web console and through the command-line interface.

* Gained the ability to combine AWS Management Console and AWS CLI to manage AWS resources more flexibly.

* Built an important foundation for the following weeks, especially for topics related to application deployment and project development on AWS.
