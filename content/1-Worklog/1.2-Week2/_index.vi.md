### Kết quả đạt được tuần 2:

* Hiểu được khái niệm cơ bản về điện toán đám mây và vai trò của AWS trong việc cung cấp hạ tầng, nền tảng và dịch vụ cloud.

* Nắm được các nhóm dịch vụ AWS cơ bản, bao gồm:

  * Compute
  * Storage
  * Networking
  * Database
  * Security
  * Monitoring

* Đã tạo thành công tài khoản AWS Free Tier để phục vụ cho việc học tập và thực hành các dịch vụ AWS.

* Làm quen với AWS Management Console và biết cách:

  * Tìm kiếm dịch vụ trên AWS
  * Truy cập giao diện quản lý của từng dịch vụ
  * Xem thông tin tài nguyên
  * Tạo và quản lý một số tài nguyên cơ bản

* Cài đặt và cấu hình AWS CLI trên máy tính cá nhân, bao gồm:

  * Access Key
  * Secret Key
  * Default Region
  * Output Format

* Biết sử dụng AWS CLI để thực hiện một số thao tác cơ bản như:

  * Kiểm tra thông tin cấu hình tài khoản AWS
  * Xem danh sách region
  * Truy vấn thông tin dịch vụ EC2
  * Tạo và quản lý Key Pair
  * Kiểm tra thông tin các tài nguyên đang hoạt động

* Hiểu được các thành phần cơ bản của Amazon EC2, bao gồm:

  * EC2 Instance
  * AMI
  * Instance Type
  * Security Group
  * Key Pair
  * EBS Volume

* Thực hành tạo EC2 Instance thành công và kết nối vào máy chủ bằng SSH.

* Biết cách gắn thêm EBS Volume vào EC2 Instance và kiểm tra dung lượng lưu trữ trên máy chủ.

* Hiểu được sự khác nhau giữa việc quản lý tài nguyên AWS bằng giao diện web và bằng dòng lệnh CLI.

* Có khả năng kết hợp AWS Management Console và AWS CLI để quản lý tài nguyên AWS một cách linh hoạt hơn.

* Tích lũy được kiến thức nền tảng quan trọng để chuẩn bị cho các tuần tiếp theo, đặc biệt là các nội dung liên quan đến triển khai ứng dụng và xây dựng project trên AWS.
