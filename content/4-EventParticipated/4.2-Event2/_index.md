# Reflection Report – Saturday Meet Up (June 6, 2026)

## Event Objectives

The **Saturday Meet Up** was organized to introduce participants to the latest technologies in **Cloud Computing, DevOps, Cyber Security, Artificial Intelligence, and Software Development**. The event aimed to:

- Update participants on modern cloud technologies and industry trends.
- Share practical experiences from professionals working in Cloud Computing, System Administration, and Software Engineering.
- Introduce AWS services such as **Amazon CloudFront, AWS WAF, Amazon Bedrock, Amazon Neptune, API Gateway WebSocket, AWS Lambda, Amazon DynamoDB**, and Cloud Native solutions.
- Demonstrate how modern technologies can be applied to software development, system security, AI applications, multiplayer games, and career development.

## Speakers

- **Bao Huynh** – *Docker: A Containerization Technology*
- **Le Hoang Gia Dai** – *Machine Learning-based Network Intrusion Detection System (AWS WAF + ML)*
- **Nguyen Quoc Bao** – *Multiplayer in the Cloud: Connecting Godot Clients with AWS WebSockets*
- **Truong Huy Phuoc** – *The Art of Effective Teamwork*
- **Viet Phat** – *Build GraphRAG Applications Using Amazon Bedrock and Amazon Neptune*
- **Tran Trung Vinh** – *From IT Helpdesk to Senior Sysadmin*

## Event Highlights

### Docker – A Containerization Technology

- Introduced the concepts of virtualization and containerization.
- Compared Virtual Machines and Docker Containers in terms of performance, scalability, and resource consumption.
- Explained Docker Images, Docker Containers, and Dockerfiles.
- Demonstrated the workflow of building images, creating containers, and deploying applications.
- Presented Docker applications in Microservices, CI/CD, Cloud Native Applications, and development environments.

### Machine Learning-based Network Intrusion Detection System

- Explained the role of AWS WAF in protecting web applications.
- Discussed the limitations of traditional rule-based detection.
- Introduced a Machine Learning-based Network Intrusion Detection System (NIDS).
- Demonstrated data preprocessing using the CSE-CIC-IDS2018 dataset and training a LightGBM model.
- Presented an AWS architecture using Amazon EC2, AWS Lambda, Amazon S3, Amazon CloudWatch, Amazon GuardDuty, AWS Security Hub, and Amazon SNS.
- Showed how Machine Learning can improve threat detection when integrated with AWS WAF.

### Multiplayer in the Cloud with AWS WebSockets

- Introduced different multiplayer networking models.
- Compared HTTP Polling, WebSocket, and UDP/ENet.
- Demonstrated a multiplayer architecture using API Gateway WebSocket, AWS Lambda, and Amazon DynamoDB.
- Explained player connection management, matchmaking, and real-time synchronization.
- Showed a multiplayer game demo developed with Godot Engine.
- Compared API Gateway WebSocket with AWS GameLift for multiplayer game development.

### The Art of Effective Teamwork

- Shared four key principles of effective teamwork.
- Discussed goal setting and task allocation.
- Explained the importance of open communication and active listening.
- Highlighted individual responsibility within a team.
- Introduced collaboration tools such as Trello, ClickUp, Slack, Discord, and Google Workspace.

### GraphRAG with Amazon Bedrock and Amazon Neptune

- Introduced Retrieval-Augmented Generation (RAG).
- Explained the limitations of traditional RAG.
- Presented GraphRAG and Multi-hop Reasoning.
- Demonstrated GraphRAG implementation using Amazon Bedrock Knowledge Bases and Amazon Neptune.
- Compared Fully Managed and Custom Pipeline architectures.
- Explained how Knowledge Graphs improve AI response quality.

### From IT Helpdesk to Senior Sysadmin

- Shared a career journey from IT Helpdesk to Senior System Administrator.
- Discussed essential technical skills for Helpdesk and System Administration.
- Explained the transition from On-Premise infrastructure to Cloud and DevOps.
- Introduced Infrastructure as Code (IaC), Docker, CI/CD, and Cloud thinking.
- Shared interview experiences, portfolio development, and career advice.

## Event Experience

The **Saturday Meet Up** provided valuable insights into emerging technologies in **Cloud Computing, DevOps, Cyber Security, Artificial Intelligence, and Software Development**. Through the presentations, I gained a deeper understanding of how these technologies are applied in real-world business environments and enterprise solutions.

I was particularly interested in the sessions about **Docker**, **Machine Learning integrated with AWS WAF**, and **GraphRAG using Amazon Bedrock**. These topics broadened my understanding of containerized application deployment, intelligent security solutions, and modern AI architectures. The presentation on **Multiplayer Game Development on AWS** also helped me understand how services such as API Gateway WebSocket, AWS Lambda, and Amazon DynamoDB work together to support real-time communication.

Beyond the technical knowledge, I also learned valuable lessons about teamwork, project organization, and career development in Cloud Computing and DevOps. The speakers' real-world experiences inspired me to continue improving my technical skills and preparing for future professional challenges.

- GraphRAG, together with Amazon Bedrock and Amazon Neptune, provides a powerful approach for building intelligent AI applications with improved reasoning capabilities.

- Successful teamwork requires not only technical expertise but also effective communication, collaboration, and project management skills.
